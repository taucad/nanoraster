## Operations

- `renderGlbToImage` renders one view.
- `renderGlbToImages` renders an ordered set of identified views.
- `createRenderImageOptions` and `createRenderImagesOptions` preserve literal
  option types while rejecting extra keys.

## Validation constants

`renderImageDimensionRange`, `renderImageQualityRange`,
`renderImageMarginRange`, `renderImageAnnotatedMinDimension`,
`renderImageLabelMaxLength`, `renderImageLabelPattern`,
`renderImageViewIdPattern`, and `renderImageBackgroundPattern` expose the
runtime validation contract. `imageMimeTypes` maps every output format to its
MIME type.
