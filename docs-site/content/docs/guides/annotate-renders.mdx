---
title: Annotate renders
description: Add an axis indicator, a caller-authored label, and a physical scale bar, and meet the minimum dimensions they require.
---

Draw an orientation indicator, a label, and a scale bar into the image so a
render still carries its context once it is separated from the request that
produced it.

## Prerequisites

- Completed the [Quick start](../getting-started/quick-start).
- Output at least 192 pixels on both sides — see step 4.

## Steps

### 1. Add the axis indicator

```typescript
import { renderGlbToImage } from 'nanoraster';

const image = await renderGlbToImage(glb, {
  format: 'png',
  width: 512,
  height: 512,
  includeAxes: true,
});
```

A camera-aware XYZ indicator is drawn in the bottom-right, along with a front-on
depth marker. It rotates with the camera, so it reports the orientation of the
view rather than a fixed key.

### 2. Add a label

```typescript
const image = await renderGlbToImage(glb, {
  format: 'png',
  width: 512,
  height: 512,
  includeLabel: true,
  label: 'Housing — front',
});
```

The label is drawn top-left, screen-upright, and rendered verbatim. It accepts
1–64 Unicode code points from a supported set that covers ASCII plus the micro
sign, em dash, and minus sign.

Enabling labels makes `label` mandatory. In a
[batch call](render-multiple-views) that requirement applies to every view, and
TypeScript enforces it before the call runs.

### 3. Add a physical scale

<RenderDemo>

```typescript
import { renderGlbToImage } from 'nanoraster';

const image = await renderGlbToImage(glb, {
  format: 'png',
  width: 512,
  height: 512,
  includeAxes: false,
  includeScale: true,
  includeLabel: false,
});
```

</RenderDemo>

A scale bar is drawn bottom-left in the model's own units. Under a perspective
projection the bar is only accurate at one depth, so its label names that plane
with `@ center`. Under an orthographic projection scale is depth-invariant and
the qualifier is dropped.

If the measurement needs to be unambiguous, render it orthographically — see
[Frame the model](frame-the-model).

### 4. Meet the minimum dimensions

Annotations need room to stay legible, so enabling any of them raises the
minimum output size to **192 pixels** on both axes. A smaller request fails
validation rather than producing an unreadable overlay.

```typescript
const image = await renderGlbToImage(glb, {
  format: 'png',
  width: 192,
  height: 192,
  includeAxes: true,
});
```

Below that, drop the annotations and keep the plain render.

## Variations

**All three at once.** They occupy different corners — axes bottom-right, label
top-left, scale bottom-left — so they can be combined without overlapping.

**Annotations plus a tight fit.** Overlays are drawn inside the frame, so a
`margin` near `0` can put the subject underneath them. Keep the default margin
when annotating.
