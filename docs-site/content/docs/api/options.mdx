Use `createRenderImageOptions` or `createRenderImagesOptions` when you want
TypeScript to preserve literal values and reject extra keys before rendering.

## Shared values

### `RenderImageFormat`

```typescript
export type RenderImageFormat = 'png' | 'webp' | 'jpeg' | 'jpg';
```

| Value  | Meaning                                                 |
| ------ | ------------------------------------------------------- |
| `png`  | Lossless PNG output with alpha support.                 |
| `webp` | WebP output with alpha support.                         |
| `jpeg` | JPEG output; requires an opaque background.             |
| `jpg`  | Alias for `jpeg`; filenames retain the `jpg` extension. |

### `RenderUpAxis`

```typescript
export type RenderUpAxis = 'x' | 'y' | 'z';
```

| Value | Meaning                                                           |
| ----- | ----------------------------------------------------------------- |
| `x`   | Treat world X as up.                                              |
| `y`   | Treat world Y as up; this is the default and the glTF convention. |
| `z`   | Treat world Z as up.                                              |

### `RenderProjection`

```typescript
export type RenderProjection = 'perspective' | 'orthographic';
```

| Value          | Meaning                                                  |
| -------------- | -------------------------------------------------------- |
| `perspective`  | Perspective camera; the default for ordinary thumbnails. |
| `orthographic` | Depth-invariant projection for canonical views.          |

## Lighting

`lighting` is a shared field: one rig applies to a singular render and to every
view of a batch. Omitting it, passing `'studio'`, and passing the studio values
written out produce the same bytes.

### `RenderLighting`

```typescript
export type RenderLighting = RenderLightingPreset | RenderLightingRig;
```

A preset name or an explicit rig. Defaults to `'studio'`.

### `RenderLightingPreset`

```typescript
export type RenderLightingPreset = 'studio';
```

| Value      | Meaning                                                                         |
| ---------- | ------------------------------------------------------------------------------- |
| `'studio'` | Three view-space lights, ambient `0.02`, and the analytic environment. Default. |

### `RenderLightingRig`

```typescript
export type RenderLightingRig = {
  readonly lights: readonly RenderLight[];
  readonly ambient?: number;
  readonly environment?: RenderLightingEnvironment;
  readonly space?: RenderLightSpace;
  readonly exposure?: number;
};
```

`lights` replaces the studio lights entirely; the remaining fields default to
the studio values, so a partial rig is complete.

### `RenderLight`

```typescript
export type RenderLight = {
  readonly direction: readonly [number, number, number];
  readonly color: readonly [number, number, number];
};
```

One directional light. `direction` points from the surface toward the light and
is normalised by the renderer; view-space axes are `+x` right, `+y` up, and `+z`
toward the viewer. `color` is linear radiance, unitless.

<auto-type-table path="./props.ts" name="RenderLight" caption="RenderLight properties" />

### `RenderLightSpace`

```typescript
export type RenderLightSpace = 'view' | 'world';
```

| Value     | Meaning                                                                                         |
| --------- | ----------------------------------------------------------------------------------------------- |
| `'view'`  | Camera-relative, so every view of a subject is lit identically. The default.                    |
| `'world'` | glTF world coordinates whatever `up` is; the rig stays fixed to the model as the camera orbits. |

### `RenderLightingEnvironment`

```typescript
export type RenderLightingEnvironment = 'studio' | 'none';
```

| Value      | Meaning                                                                             |
| ---------- | ----------------------------------------------------------------------------------- |
| `'studio'` | Analytic environment supplying specular reflection and diffuse irradiance. Default. |
| `'none'`   | Neither term; only the supplied lights and ambient contribute.                      |

## Batch request

### `RenderImageView`

```typescript
export type RenderImageView<Id extends string = string> = {
  readonly id: Id;
  readonly label?: string;
  readonly phi: number;
  readonly theta: number;
};
```

IDs must be unique within a request. Angles are finite degrees; `phi` is polar
from the selected up axis and `theta` is right-handed azimuth around that axis.

<auto-type-table path="./props.ts" name="RenderImageView" caption="RenderImageView properties" />

### `RenderImagesOptions`

```typescript
export type RenderImagesOptions<Views extends readonly RenderImageView[] = readonly RenderImageView[]> =
  RenderImageSharedOptions &
    (
      | { readonly includeLabel: true; readonly views: LabeledViews<Views> }
      | { readonly includeLabel?: false; readonly views: Views }
    );
```

`views` must be a non-empty ordered tuple with unique IDs. When `includeLabel`
is `true`, every view must carry a label. `LabeledViews` is the internal mapped
tuple that enforces that relationship without losing IDs or order.
